🤖 AUTO DUTY

🤖 Auto Duty Config

Only one mode can be ON at a time. Mode 3 publishes at the next saved clock time and shows a persistent countdown. Settings are saved by the server.

Mode 1 · Confirm, save and publish
After all assigned duties are confirmed, wait for Delay Time, then save the confirmed assignment to its Duty Register date. The Publish Time countdown starts while the server prepares the selected sheet. When that countdown reaches zero, publish the prepared sheet immediately. Turning OFF pauses new automation but keeps the current published assignment visible while you choose the next source.
OFF

Mode 2 · Confirm, countdown and publish
After all assigned operators confirm, Mode 2 starts its own countdown. It saves the confirmed duty to the matching Duty Register date after Delay Time, prepares the selected sheet, and publishes it when Publish Time ends. This mode does not use a scheduled clock time.
OFF

Mode 2 timing

Mode 3 · Supervisor advance lineup auto mode
At the next occurrence of the saved time, save the current Check Position and Confirm Duty assignment to its Duty Register date, then publish the selected sheet. If today’s time has passed, it schedules tomorrow. The published assignment stays active until confirmation or an Admin settings save.
OFF
